# AVL Tree Visualizer

An interactive web-based AVL Tree visualization tool that demonstrates
self-balancing Binary Search Tree operations step by step.

##  Features
- Step-by-step AVL tree insertion
- Balance factor displayed on each node
- Visualized rotations (LL, LR, RL, RR)
- Animated node comparisons
- Clean and intuitive UI

##  Tech Stack
- HTML
- CSS
- JavaScript 

##  How to Use
1. Enter a number in the **Insert** box
2. Click **Insert**
3. Observe comparisons, balance factors, and rotations
4. Use visual highlights to understand tree balancing
